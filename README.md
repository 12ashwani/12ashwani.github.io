# Ashwani Kumar Portfolio

Personal portfolio website showcasing experience, education, and project categories across analytics and automation.

## Run Locally

```powershell
cd "e:\all projects\portfolio web\12ashwani.github.io"
python -m http.server 5500
```

Open: `http://localhost:5500/index.html`

## Main Pages

- `index.html`
- `about.html`
- `exp.html`
- `edu.html`
